# 裁判学习一站式平台

## 这是什么

项目收录 **2024、2025、2026 三个赛季共81期中国足协裁判评议**：2026赛季进行中（已收22期、225个判例、224段视频，持续更新）；2025赛季32期、227个判例、229段视频；2024赛季27期、160个判例、161段视频。判例按统一尺度教学分类重组，并附判定与影响统计。另收录官方 **《统一判罚尺度》宣讲合集**（scale.html，2026+2025 两季 58 例典型场景视频+判罚决定对照）与 **《足球竞赛规则 2026/27》简体中文版**（rules.html，支持全文搜索、划词高亮和章节笔记）。

在线版本：<https://rolandhuang17.github.io/cfa-referee-review/>

- 数据来源：中国足球协会官方网站「裁判评议结果发布」栏目；竞赛规则来自 The IFAB 官方下载（版权说明见 [NOTICE.md](NOTICE.md)）。
- 每条判例卡片均附官方原文链接，判定结论引用评议组认定原文

## 怎么用

1. 进入 `site/`，双击 `index.html`，用 Edge / Chrome 打开即可。
2. 如需视频，将视频下载到 `site/videos/2024/`、`site/videos/2025/` 和 `site/videos/2026/`。
3. 也可以直接访问 GitHub Pages 在线版本——建议在首页选择「**轻量版**」（纯文字+官方链接，无需下载任何视频）；完整版在线访问时若本地视频缺失，会自动改用官方直链在线播放。

页面功能（三栏工作台：左侧筛选侧栏，中间播放列表，右侧大屏详情；支持明暗主题切换与移动端适配）：

| 功能 | 说明 |
|---|---|
| 顶栏 | 全站统一导航、搜索（按 `/` 聚焦）、说明弹层、侧栏开关、轻量版开关、明暗主题切换（跟随系统偏好） |
| 浏览模式 | 首页分段开关或顶栏「轻量版」随时切换：**轻量版**=无视频窗口，判例详情为纯文字阅读+加大笔记区，附「打开官方评议页」（按期跳转官方文章）与每条判例的官方视频直链（新标签页在线播放），笔记本式界面，适合纯在线访问；**完整版**=内嵌视频播放器，适合本地离线学习。两种模式共用收藏与笔记 |
| 左侧栏 | 全部筛选一处搞定：判定（错漏判/支持原判/不予认定）、我的收藏（按标签）、赛事、球队（带队徽，跨赛事聚合）、期数（数字网格）、10个教学分类 |
| 播放列表 | 按教学分类分组，一行一例密集排布，状态色点+对阵（带徽）+VAR标记 |
| 详情区 | 大视频播放器（懒加载，切换判例即换片）+ 事件描述 + 申诉意见 + 评议组认定原文 + 分类统一尺度要点 + 标签 + 原文链接 |
| 键盘操作 | `↑`/`↓` 上一个/下一个判例（宣讲核心操作），`/` 聚焦搜索，`Esc` 关闭弹层 |
| 收藏与笔记 | 收藏判例并打多标签（精选/有疑问/尺度标杆/易错点/课堂讨论/自定义）、逐判例学习笔记（自动保存）、按标签筛选、导出/导入 JSON 同步 |
| 队徽 | 111 个标准队伍统一目录；来源已核验的显示真实队徽，其余显示标准文字徽章，不自动猜图 |
| 统一尺度宣讲 | 官方《统一判罚尺度》2026+2025 两季共 58 例典型场景（争抢/战术犯规/手球/罚球区事件/比赛管理/越位/VAR/规则变更），每例含官方视频、说明与判罚决定对照 |
| 各队得失盘点 | 独立页面 stats-2026/2025/2024.html（见下） |
| 响应式 | ≤1080px 侧栏变抽屉、列表/详情切换；手机/平板可正常学习 |

## 各队得失盘点

独立的错漏判影响统计页面（主页有入口链接），按赛季统计男子中超/中甲/中乙及足协杯的官方认定错漏判，提供**受损方/获益方双视角**：

- 每队一张卡片：漏判进球、对方应无效进球、漏判/错判点球、红黄牌错误等分类计数，可展开逐条明细（比分、修正比分、判例链接、说明）
- **比分修正比对**：逐场查证比赛最终比分（来源见页脚；2026赛季随赛季进行逐步补齐，缺失显示「待补」），对进球判定类错误计算修正比分——修正后积分提高记为「结果或被改变」，另有漏判点球/红牌等机会因素且分差≤1的记为「存在影响可能」
- 红黄牌类错误全部计入；点球作为机会因素不折算进球；不推算积分榜连锁影响
- 明细每条可跳转回主合集对应判例卡片（含视频）

## 教学分类（10类）

手球犯规 / 越位 / 罚球区内判罚（点球）/ 罚球区外一般犯规 / 战术犯规与SPA / 破坏明显进球得分机会（DOGSO）/ 严重犯规与暴力行为 / 假摔与欺骗行为 / 进球判定与有利条款 / 程序与其他

每类开头「统一尺度要点」提炼自各赛季评议中反复强调的判罚尺度，配合该类判例视频对照学习。

## 统计口径

- **2026赛季（进行中）**：错漏判 95 例 / 支持原判 121 例 / 不予认定 9 例；VAR错误 14 例
- **2025赛季**：错漏判 82 例 / 支持原判 138 例 / 不予认定 7 例；VAR错误 14 例
- **2024赛季**：错漏判 60 例 / 支持原判 99 例 / 不予认定 1 例
- 官方各期标题认定数与合集口径的差异（如「申诉问题正确但另漏判黄牌」「本轮中超无错漏判」只计中超等）已在页面「说明」弹层中按期注释

## 从 GitHub 克隆后如何使用

视频体积太大（三赛季约 30GB）不进仓库。克隆后：

```bash
python scripts/download_videos_parallel.py 2026
python scripts/download_videos_parallel.py 2025
python scripts/download_videos_parallel.py 2024
```

然后双击 `site/index.html` 即可。不下载视频也能正常使用：在线访问推荐用「轻量版」（纯文字+官方链接，笔记功能完整），完整版则会自动改用官方直链在线播放。

## 重新生成或扩展

依赖 Python 3.8+；规则页构建需要 `scripts/requirements-build.txt` 中的依赖。标准构建命令：

```bash
python -m pip install -r scripts/requirements-build.txt
python scripts/build_all.py
python scripts/verify_project.py
python scripts/serve.py
```

抓取和数据管线、安全网络要求、赛季接入指南见 `AGENTS.md`；GitHub Actions 会自动构建并发布 `site/`。
