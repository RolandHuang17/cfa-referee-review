# 裁判学习一站式平台

## 这是什么

项目收录 **2024、2025 两个赛季共59期中国足协裁判评议**：2025赛季32期、227个判例、229段视频；2024赛季27期、160个判例、161段视频。判例按统一尺度教学分类重组，并附判定与影响统计。另收录 **《足球竞赛规则 2026/27》简体中文版**（rules.html，支持全文搜索、划词高亮和章节笔记）。

在线版本：<https://rolandhuang17.github.io/cfa-referee-review/>

- 数据来源：中国足球协会官方网站「裁判评议结果发布」栏目；竞赛规则来自 The IFAB 官方下载（版权说明见 [NOTICE.md](NOTICE.md)）。
- 每条判例卡片均附官方原文链接，判定结论引用评议组认定原文

## 怎么用

1. 进入 `site/`，双击 `index.html`，用 Edge / Chrome 打开即可。
2. 如需视频，将视频下载到 `site/videos/2024/` 和 `site/videos/2025/`。
3. 也可以直接访问 GitHub Pages 在线版本。

页面功能（双栏布局：左侧分类/判定导航，中间播放列表，右侧大屏详情）：

| 功能 | 说明 |
|---|---|
| 顶栏 | 搜索（按 `/` 聚焦）、期数筛选、统计总表弹层、说明弹层、侧栏开关 |
| 左侧栏 | 10个教学分类（含例数/错判数）、判定筛选（错漏判/支持原判/不予认定）；可收起获得全宽画面 |
| 播放列表 | 一行一例密集排布，状态色点+对阵+VAR标记，点击行在右侧查看 |
| 详情区 | 大视频播放器（懒加载，切换判例即换片）+ 事件描述 + 申诉意见 + 评议组认定原文 + 标签 + 原文链接 |
| 键盘操作 | `↑`/`↓` 上一个/下一个判例（宣讲核心操作），`/` 聚焦搜索，`Esc` 关闭弹层 |
| 收藏与笔记 | ⭐收藏判例并打多标签（精选/有疑问/尺度标杆/易错点/课堂讨论/自定义）、逐判例学习笔记（自动保存）、侧栏「我的收藏」按标签筛选、导出/导入 JSON 同步 |
| 队徽 | 播放列表与详情中球队名前显示真实俱乐部徽章（男子中超/中甲/中乙 36 队，B队沿用母俱乐部徽章，未收录球队显示首字占位） |
| 各队得失盘点 | 独立页面 stats-2025.html / stats-2024.html（见下） |

## 各队得失盘点

独立的错漏判影响统计页面（主页顶部有入口链接），按赛季统计男子中超/中甲/中乙及足协杯的官方认定错漏判，提供**受损方/获益方双视角**：

- 每队一张卡片：漏判进球、对方应无效进球、漏判/错判点球、红黄牌错误等分类计数，可展开逐条明细（比分、修正比分、判例链接、说明）
- **比分修正比对**：已逐场查证60场比赛的最终比分（来源见页脚），对进球判定类错误计算修正比分——修正后积分提高记为「结果或被改变」（8例），另有漏判点球/红牌等机会因素且分差≤1的记为「存在影响可能」
- 红黄牌类错误全部计入；点球作为机会因素不折算进球；不推算积分榜连锁影响
- 明细每条可跳转回主合集对应判例卡片（含视频）

## 教学分类（10类）

手球犯规 / 越位 / 罚球区内判罚（点球）/ 罚球区外一般犯规 / 战术犯规与SPA / 破坏明显进球得分机会（DOGSO）/ 严重犯规与暴力行为 / 假摔与欺骗行为 / 进球判定与有利条款 / 程序与其他

每类开头「统一尺度要点」提炼自本赛季评议中反复强调的判罚尺度，配合该类判例视频对照学习。

## 统计口径

- **错漏判（82例）**：评议组认定裁判员/助理裁判员判罚决定错误或漏判
- **支持原判（138例）**：评议组支持临场判罚决定
- **不予认定（7例）**：现有视频无法判断，评议组不做认定
- **VAR错误（14例）**：单独统计，含介入错误与应介入未介入
- 官方各期标题合计「认定83例错漏判」，与本合集口径的差异已在页脚「期数口径注释」中说明：
  - 第9期的第6例为 **VAR越位划线错误**（对裁判员判定不予认定），本合集计入VAR统计
  - 第26期判例七当期未认定、由第27期补充认定为漏判红牌，本合集随原判例计入第26期


## 从 GitHub 克隆后如何使用

视频体积太大（约26GB）不进仓库。克隆后：

```bash
python scripts/download_videos_parallel.py 2025
python scripts/download_videos_parallel.py 2024
```

然后双击 `site/index.html` 即可。若只看文字与统计，不下载视频也能正常使用（仅无画面）。

## 重新生成或扩展

依赖 Python 3.8+；规则页构建需要 `scripts/requirements-build.txt` 中的依赖。标准构建命令：

```bash
python -m pip install -r scripts/requirements-build.txt
python scripts/build_all.py
python scripts/verify_project.py
python scripts/serve.py
```

抓取和数据管线、安全网络要求见 `AGENTS.md`；GitHub Actions 会自动构建并发布 `site/`。

如需收录新赛季，先在对应抓取脚本中加入期数和数据配置，再运行完整构建与校验。
