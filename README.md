# 2025赛季中国足协裁判评议全集 · 教学合集

## 这是什么

本合集收录 **2025赛季中国足协官方发布的全部32期裁判评议**（2025-02-27 至 2025-11-05），共 **227个判例、229段评议视频**。全部判例已按新裁判统一尺度教学的标准分类重新组织，并附正确/错误统计，用于向新裁判集中宣讲学习。

- 数据来源：中国足球协会官方网站「裁判评议结果发布」栏目（第1—23期原发布于赛事新闻栏目）
- 每条判例卡片均附官方原文链接，判定结论引用评议组认定原文

## 怎么用

1. **保持 `index.html` 和 `videos` 文件夹在一起**（这是唯一的结构要求）
2. 双击 `index.html`，用 Edge / Chrome 等浏览器打开即可——**完全离线可用**
3. 整个文件夹拷贝到U盘、教室电脑均可直接放映

## 各队得失盘点（stats.html）

独立的错漏判影响统计页面（主页顶部有入口链接），**仅统计男子中超/中甲/中乙**的官方认定错漏判（67例/60场/38队），提供**受损方/获益方双视角**：

- 每队一张卡片：漏判进球、对方应无效进球、漏判/错判点球、红黄牌错误等分类计数，可展开逐条明细（比分、修正比分、判例链接、说明）
- **比分修正比对**：已逐场查证60场比赛的最终比分（来源见页脚），对进球判定类错误计算修正比分——修正后积分提高记为「结果或被改变」（8例），另有漏判点球/红牌等机会因素且分差≤1的记为「存在影响可能」
- 红黄牌类错误全部计入；点球作为机会因素不折算进球；不推算积分榜连锁影响
- 明细每条可跳转回主合集对应判例卡片（含视频）

## 教学分类（10类）

手球犯规 / 越位 / 罚球区内判罚（点球）/ 罚球区外一般犯规 / 战术犯规与SPA / 破坏明显进球得分机会（DOGSO）/ 严重犯规与暴力行为 / 假摔与欺骗行为 / 进球判定与有利条款 / 程序与其他

每类开头「统一尺度要点」提炼自本赛季评议中反复强调的判罚尺度，配合该类判例视频对照学习。

## 统计口径

- **错漏判（82例）**：评议组认定裁判员/助理裁判员判罚决定错误或漏判
- **支持原判（138例）**：评议组支持临场判罚决定
- **不予认定（7例）**：现有视频无法判断，评议组不做认定
- **VAR错误（14例）**：单独统计，含介入错误与应介入未介入
- 官方各期标题合计「认定83例错漏判」，与本合集口径的差异已在页脚「期数口径注释」中说明：
  - 第9期的第6例为 **VAR越位划线错误**（对裁判员判定不予认定），本合集计入VAR统计
  - 第26期判例七当期未认定、由第27期补充认定为漏判红牌，本合集随原判例计入第26期

## 目录结构

```
2025评议整理/
├── index.html          ← 合集页面（双击打开）
├── stats.html          ← 各队得失盘点（错漏判影响统计）
├── videos/             ← 229段评议视频（约16GB，按 期i判例c-序号 命名）
├── data/
│   ├── cases.json      ← 全部判例结构化数据（含分类、标签、结论）
│   ├── impact.json     ← 错漏判影响标注（受损队/类型/得失球）
│   ├── match_scores.json ← 60场比赛最终比分（含来源）
│   ├── issues_raw/     ← 32期官方页面存档（原始HTML）
│   └── review.txt      ← 判例纯文本汇编（便于打印速查）
└── scripts/            ← 抓取/解析/下载/生成脚本（可复用于其他赛季）
```

## 从 GitHub 克隆后如何使用

视频体积太大（约16GB）不进仓库。克隆后：

```bash
cd scripts
python download_videos_parallel.py   # 重新下载229段视频（断点续传，约1-3小时）
```

然后双击 `index.html` 即可。若只看文字与统计，不下载视频也能正常使用（仅无画面）。

## 重新生成或扩展

依赖 Python 3.8+（无需第三方库，仅标准库）。按顺序：

```bash
cd scripts
python fetch_issues.py       # 1. 抓取32期官方页面
python parse_issues.py       # 2. 解析为结构化判例
python download_videos_parallel.py   # 3. 下载视频（断点续传，可中断重跑）
python classify_cases.py     # 4. 合并教学分类（分类表在脚本内，可修改）
python make_impact.py        # 5. 合并错漏判影响标注（受损队/类型在脚本内）
python build_page.py         # 6. 重新生成 index.html
python build_stats.py        # 7. 重新生成 stats.html（比分在 data/match_scores.json）
```

如需收录2026赛季（截至2026年9月已发布22期），在 `fetch_issues.py` 的 `ISSUES` 表中补入新一期URL后重跑上述流程即可。
