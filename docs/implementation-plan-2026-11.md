### A1　修正答题、改选和空答计分

**复现入口**　线上规则理论题“判断越位位置时，身体哪部分不计入”。用鼠标先点“躯干”，再点“上肢及手部”，提交后曾同时高亮两个选项，系统取了“躯干”，判 0/1。另用实际计分函数给全部 97 道尺度题传入空选择，96 道得 1/2，2024-G4 得 2/2。 [答题页生成器](../scripts/build_quiz.py) · [题库入选条件](../scripts/lib/site_stats.py)

**实施顺序**

1. 统一鼠标、触屏、数字键的单选状态。理论题按显示顺序渲染，存储原始选项下标，数值 `0` 也是有效答案。回到上一题时恢复原选择。尺度题继续支持多选。
2. 尺度题空答或出现错项计 0 分，只勾到部分正确项计 1 分，完全匹配计 2 分。手动提交、跳过和考试超时共用同一判分入口。结果页、错题本和导出对空答显示“未作答”。
3. 对照 2024 官方尺度材料核验 G4。若矩阵有可证实的决定，修正提取或校订依据。若材料不足以出题，宣讲页保留场景、题库排除并说明原因。入池条件与首页、搜索和题量统计使用同一口径。
4. 检查旧错题 JSON、Leitner 档位及作答历史的读写。新规则用于新作答。过去缺少原始作答证据的成绩保留原记录。

**验收**　浏览器完成“错选 → 改选正确 → 提交”“正确原始下标为 0 → 离开 → 返回”“选两项的尺度题 → 取消一项”。练习、考试和超时交卷均覆盖空答。一次提交只增加一次作答记录。用一道部分正确和一道含错选的尺度题核对分值。题库内每道可判分尺度题都有可解释的有效答案。

### B6　在线离线缓存、移动端与资料迁移

- Service Worker 的清理范围限定在**当前部署路径拥有的缓存**。确保首页或离线入口在安装成功后可用。页面获取失败时保留已有成功响应。为“已访问页面可离线读”的承诺设计升级迁移，避免换版本后首次断网就丢掉已学内容。
- 在同一测试 origin 下放两个项目，创建另一项目的缓存标记。访问本项目首页与一条判例，模拟发布新版本，再断网。验证另一项目标记、已读页、首页、从未访问过的页面反馈，以及旧版笔记导入。验证同域 `videos/` 与外域媒体不进入缓存。`file://` 双击运行独立于 Service Worker。 [PWA 实现](../scripts/build_pwa.py)
- 分别在 390 px 手机宽度和桌面宽度从搜索进入判例，打开筛选抽屉，隐藏及揭示答案，记笔记并返回列表，刷新后检查恢复结果。Tab、Enter、Esc 能操作关键控件，关闭抽屉后焦点回到触发按钮。视频缺失时保留官方来源入口。轻量模式可用纯文字完成阅读和笔记。
