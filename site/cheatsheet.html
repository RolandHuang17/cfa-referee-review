足球竞赛规则 2026/27 · 卡面要点与完整细则

✋手球判罚考量

查看细则翻回速记

判犯规

  • 并非每次球碰手都犯规；两个条件满足其一即犯规
  • 手/臂位置非身体动作结果或不能证实是身体动作所致 → 视为身体不自然扩大

与进球相关（即使意外）

  • 球直接从手/臂送入对方球门 → 无效
  • 手/臂触球后立即射门入对方球门 → 无效

守门员特例（己方罚球区内）

  • 队友蓄意脚踢回传 / 界外球直接掷回，用手接 → 间接任意球
  • 放球后未经他人触球再用手触球 → 间接任意球
  • 用手持球超过八秒才放出 → 判对方角球（最后五秒举手示意倒计时）

评议口径提示

  • 判罚考量链：触球点是否腋窝以下 → 手臂是否不自然扩大/扬起 → 距离与反应时间 → 是否直接导致进球/进球机会
  • 紧贴身体、被动被球击中通常不判；张开扬臂扩大防守面积通常判罚

腋窝为界 · 两个犯规条件 · 两种进球无效

  • 肩臂分界线 = 腋窝
  • 犯规条件①：蓄意用手/臂触球（手移向球）
  • 犯规条件②：身体不自然扩大时触球
  • 意外触球后立即射门得分 → 进球无效
  • 守门员禁区外手球限制同其他球员

⚖犯规程度三档

查看细则翻回速记

三档定义（第12章原文）

  • 不小心：没有事前专注或事先考虑下与对方争夺球
  • 鲁莽：争夺球时没有顾及对方球员的危害或后果
  • 使用过分力量：动作力量超出需要及/或伤害和危及对方球员

直接任意球犯规（身体接触类）

  • 冲撞 / 跳向 / 踢或意图踢 / 推 / 击打或意图击打（含用头顶撞）/ 拦截或冲击 / 绊倒或意图绊倒
  • 另有：手球、拉扯、有身体接触的阻碍、咬或吐唾沫、持物触球

间接任意球（无接触/程序类）

  • 危险动作 / 无接触的阻碍 / 言语不满 / 阻挠守门员放球 / 诡计回传门将 / 守门员禁区内的二次触球与回传

不小心无处分 · 鲁莽黄牌 · 过分力量红牌

  • 不小心 → 无须纪律处分
  • 鲁莽（不顾及对方危害）→ 黄牌
  • 使用过分力量（伤害危及对方）→ 红牌
  • 不危及对方安全的剪刀脚/倒挂 → 允许

🚫DOGSO 与 SPA

查看细则翻回速记

须黄牌的欠缺体育精神情形（与机会相关）

  • 破坏对方进球/明显进球机会，且被判点球、属非蓄意手球
  • 意图争夺球犯规破坏明显进球机会且被判点球
  • 手球或犯规干扰/阻止明显进攻机会（点球+争夺球例外）
  • 蓄意用手触球取得进球（无论是否成功）

有利原则红线

  • 严重犯规、凶暴行为、第二次黄牌：除非当时有明显进球机会，否则不应运用有利
  • DOGSO 运用有利后非犯规方进球 → 不再执行纪律处分；未进球 → 黄牌（欠缺体育精神）
  • SPA 运用有利 → 不需要补黄牌

破坏机会的纪律处分四情形

  • DOGSO（破坏明显进球机会）→ 红牌
  • 例外：点球 + 意图争夺球的犯规 → 黄牌
  • 例外：点球 + 非蓄意手球 → 黄牌
  • SPA（干扰/阻止明显进攻机会）→ 黄牌

📺VAR 可介入情形

查看细则翻回速记

可介入的判罚类别

  • 进球（及进球前的进攻过程犯规/越位/手球）
  • 罚球点球 / 罚球点球未判
  • 直接红牌（严重犯规、暴力行为、吐唾沫等）
  • 错误认定球员身份（警告/罚错人）

覆检后纪律处分

  • 原决定被改变后，此前已作出的纪律处分不可取消
  • 例外：因干扰/阻止明显进攻机会或破坏明显进球机会而出示的黄牌/红牌

场地要求

  • 必须有一个视像控制室（VOR）及最少一个裁判员覆检区域（RRA）

四大类 · 覆检不设时限 · 重开后原则不可覆检

  • 覆检原则：准确度比速度重要，不设时间限制
  • 覆检中裁判员必须保持「可见」
  • 比赛重新开始后不可覆检
  • 例外：认错球员身份 / 暴力行为类红牌

🟨红黄牌速查

查看细则翻回速记

欠缺体育精神的典型

  • 试图欺骗裁判员：假装受伤或假装被侵犯（假摔）
  • 比赛中未经准许与守门员互换位置
  • 蓄意用手触球取得进球（无论成败）
  • 诡计回传门将（头/胸/膝）逃避规则
  • 得到准许离场途中触球 / 场内划未认可记号

红牌罚令出场（球员）

  • 严重犯规 / 暴力行为（凶暴行为）
  • 咬人或向任何人吐唾沫
  • 破坏明显进球机会（DOGSO，点球例外见速查卡③）
  • 使用冒犯性、侮辱性或辱骂性言语/举动
  • 同一场比赛第二次被黄牌警告

两项分别需警告的犯规（即使时间接近）

  • 应出示两个黄牌（随后红牌罚令出场），不能合并为一张

应警告的常见情形（第12章）

  • 拖延重新开始比赛
  • 用言语或行动表示不满
  • 未得裁判员准许擅自进入/再次进入/离开场地
  • 定位球时未退离规定距离
  • 屡次触犯规则（无特定次数）
  • 欠缺体育精神（含假摔/伪装行为）

⚽罚球点球程序

查看细则翻回速记

程序要点

  • 门柱、横梁和球门网必须保持静止状态
  • 主射者与守方守门员之外的所有球员须在合规位置后方可执行
  • 防守方拉扯进攻球员从区外持续到区内 → 判点球（而非区外任意球）

点球决胜相关

  • 半场/加时结束时，比赛时间因执行点球延长至完成
  • 点球向前移动中球破损且未触及任何球员/门柱/横梁 → 重射

放定 · 九一五 · 点后区外 · 信号后必完成

  • 球：放定于罚球点，一部分触及罚球点中央
  • 其他球员：距点 ≥9.15 米、在点之后、罚球区外、场内
  • 裁判员发出讯号后，该次点球必须完成
  • 判罚条件：比赛进行中，己方罚球区内应判直接任意球的犯规

🚩越位判定三步

查看细则翻回速记

构成越位犯规的三类参与

  • 干扰比赛：接应或接触队友踢出/触及的传球
  • 干扰对方：遮挡视线、与其争球、近距离试图参与并明显影响、明确动作明显影响其处理球能力
  • 取得利益：球从门柱/横梁/官员/对方反弹或被对方蓄意救球弹回

不判越位的例外

  • 接获对方球员蓄意处理球（传/控/解围，含蓄意手球）——蓄意救球除外
  • 开球门球、界外球、角球直接接球不判（对应重新开始方式）
  • 身处越位位置本身不是犯规

判罚

  • 越位犯规 → 对方在犯规发生地点获间接任意球

位置 → 干扰 → 例外

  • 第一步·位置：头/身/脚比对方第二名最后球员及球更接近对方门线
  • 手臂与手不计入（腋窝为肩臂分界）
  • 与倒数第二名球员平行 → 不越位；半场内接球点须在对方场区
  • 第二步·干扰：接球/干扰对方/取得利益才构成犯规

🔄重新开始方式速查

查看细则翻回速记

距离与时间数字

  • 中圈开球：对方离球 9.15 米；全体在本方半场
  • 界外球：对方距掷球点 ≥2 米；拖延 5 秒未掷 → 判给对方
  • 球门球：对方留罚球区外直至开始；5 秒未开出 → 对方角球
  • 守门员持球 8 秒未放出 → 对方角球
  • 任意球：对方退 9.15 米；攻方距守方 3+ 人墙 <1 米 → 攻方间接任意球

坠球规则

  • 球在罚球区内 → 给守方门将；在区外 → 给将获/保有控球权一方
  • 在暂停时球所在位置执行；球击中官员/外物 → 在干扰位置执行
  • 球触及地面比赛即开始

球出界即停（第9章）

  • 整个球在地面或空中完全越过球门线或边线，或比赛被裁判员暂停
  • 球触官员后留在场内致明显进攻/进球/控球权改变 → 坠球

能不能直接得分 · 距离数字一页记

  • 中圈开球：可直射对方门（入己门→对方角球）
  • 球门球：可直射对方门（入己门→对方角球）
  • 界外球：不可直接得分（入对方门→球门球；入己门→角球）
  • 坠球：罚球区内给守方门将；他人须离 4 米；球触地即开始

🆕2026/27 新规速查

查看细则翻回速记

替换与时间

  • A级友谊赛：可替换8名或（双方同意并提前通知裁判员）11名，每队3次换人机会
  • 10秒离场；超时替补须待比赛重新开始1分钟后的首次暂停方可入场
  • 受伤接受评估/治理或导致比赛停止的球员：重新开始后离场并在场外逗留1分钟
  • 界外球/球门球延误：5秒明显倒计时，超时分别判对方界外球/角球

仅限队长

  • 2027-07-01起成为所有比赛强制性协定
  • 只有队长可接近裁判员（须保持尊重、行为得体）；队长专用区4米
  • 守门员是队长：赛前掷毫时或之前指定另一名球员
  • 多人进入队长区：至少黄牌警告一人（通常第一个或最激烈者）
  • 信号：双臂举过头顶、手腕交叉；随后双臂分开、手掌前推

VAR 与纪律

  • 可覆检明显错误的第二面黄牌导致的红牌
  • 可覆检犯规者为另一名球员时的错误红黄牌
  • 可覆检明显错判的角球（须能立即更改且不延迟重新开始，竞赛组织可允许）
  • 2026/27 起竞赛组织可选择为比赛官员提供随身摄像机

DOGSO / 点球

  • 运用有利并进球得分：对DOGSO犯规不再黄牌警告
  • DOGSO考虑因素新增「进攻球员」
  • 点球主射与守门员同时犯规：取消主射球员的自动黄牌警告
  • 坠球：明确控球权归属；裁判员/外来物体干扰时在干扰地点坠球

10秒换人 · 5秒界外球/球门球 · 仅限队长 · VAR新覆检

  • 被替换球员须在替换讯号后10秒内离场
  • 超时：替补须等比赛重新开始1分钟后的首次暂停
  • 界外球/球门球延误超5秒：分别改判对方界外球/角球
  • 仅限队长：队长专用区4米；2027-07-01起强制
  • VAR可覆检：错误第二黄红牌、错误球员身份、可立即更正的角球
  • 有利后进球：DOGSO不再黄牌；点球同时犯规取消主射自动黄牌
